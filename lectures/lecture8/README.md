# コトハ — 実践記録をつくるためのガイドAI


>ボクはコトハ、知恵の記録を勉強中の見習いです。
>
>今日のメモをそのまま貼ってください。箇条書きでも、感想でも、教材名だけでも大丈夫です。心に残ったことや、次に生かせそうなことも書いてくれると、うれしいです。
>
>書いてくれたことをもとに、ボクが記録としてまとめます。どう書くのか迷うことは、チャットしながら、どう残すのかを一緒に決めていきましょう。
>また、必要なことは、あとから、ボクが少しずつ聞いていきます。
>
>「こんなことあったよ」って、ボクに教えてくれる感じでお願いします！


地域日本語教室の授業メモを、記録者に負担をかけず、むしろ「話してよかった」と感じてもらいながら、共有可能な実践知として記録するための **Gemini Gem 用プロンプト** です。

このリポジトリでは、見習いの相棒「コトハ」というキャラクターを通して、支援者（多くはボランティア）が授業の気づきを語りやすくする `KOTOHA_gem_prompt.md` を公開します。これは、地域日本語教育の実践知が個人の経験に閉じてしまわず、地域の共有財産として循環していくことを目指す MVP です。


## このプロジェクトについて
「web3/AI概論2026」のマイプロジェクトとして取り組んでいるものです。
大きくは、地域の日本語教室から、共有してよい知恵と、記録してはいけないものを考える「地域の知恵・記録プロジェクト / Local Knowledge Commons Project」の一部です。
このリポジトリは、以前公開した [ai-prompt.md](https://github.com/ta5naka/ta5naka-web3ai-2026/blob/main/lectures/lecture5/ai-prompt.md) の改良版にあたります。


## なぜ「整理ツール」ではなく「相棒」なのか

授業記録は、ともすると「正しく埋める作業」になりがちです。
しかし、記録が単なる情報ではなく、その人にとっての「知恵」になるためには、**今・ここで実践している自分を肯定できる関係性**が必要ではないか。これがこのプロジェクトの仮説です。
そこで、支援者の横にいる小さな相棒、**知恵の記録を勉強中の見習い「コトハ」**というキャラクターを置きました。
- コトハは立派な記録を作ろうとしません。
- 知らないことは素直に「教えてください」と聞きます。
- 評価や採点をせず、「へぇ、それでどうなったんですか？」と続きを促します。

「教えてもらう」のではなく、「コトハに教えてあげる」。
この反転によって、記録者が誰でも教える側に回れ、実践知が自然に言葉になることを狙っています。


## このリポジトリで作成したもの
`KOTOHA_gem_prompt.md`
Gemini の Gem に貼り付けて使う、システムプロンプトです。

主な機能は次のとおりです。
- メモに書かれた事実だけで仮に埋め、推測した箇所は「（※ボクの推測です）」と明示する
- 一度に最大3項目までしか質問せず、テンポよく対話する
- 記録者の語り方（エピソード型・分析型・成果型・実務型など）に合わせて、得意な語りをそっと深める
- 学習者の表面的なニーズの奥にある「願い」を、見習いの好奇心として一度だけ問いかける


## 設計で大切にしたこと
このプロンプトには、次の原則を組み込んでいます。

- **事実と推測を分ける**：メモにない内容を創作せず、補完は「推測」と明示して人間に判断を返す
- **欠乏モデルで評価しない**：「理解が不十分」ではなく「どんな支援があれば参加可能性が広がるか」で書く
- **変化を断定しない**：内面や人格の変化を断定せず、観察された発言・行動の「兆し」として書く
- **関係性の中で見る**：変化を個人の努力に還元せず、場の相互作用の中で記述する
- **本人に返せる言葉で書く**：本人が読んでも不利益・恥・評価圧力を感じない表現にする
- **記録者の尊厳を守る**：記録者を「データ提供者」として消費しない。確定時には必ず「この記録、コミュニティの知恵として残しておいて大丈夫ですか？」と確認する

特に最後の「残しておいて大丈夫ですか？」という一言は、人を資源として勝手に蓄積するのではなく、**知恵を贈与（ギフト）として受け取る**という、このプロジェクトの思想を表したものです。


## 注意事項
- このプロンプトは、地域日本語教育の実践記録を支援するためのものです。法的判断や教育的評価を行うものではありません。
- AI の出力には誤りや不適切な解釈が含まれることがあります。記録の内容は、必ず記録者自身が確認・修正してください。
- 学習者の氏名・所属・国籍など個人を特定する情報は、プロンプト上は抽象化する設計ですが、入力時にもできるだけ含めないようご注意ください。
- 地域素材の著作権・肖像権・利用許諾については、別途十分にご確認ください。
- センシティブな内容、非公開を前提とする情報は、記録として残す前に「公開してよいか」を慎重にご判断ください。
