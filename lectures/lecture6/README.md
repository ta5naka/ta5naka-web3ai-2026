# Transformative Practice Log

地域日本語教育における実践知・対話・変容のポートフォリオを記録するためのプロジェクトです。

このリポジトリでは、入力されたURLから「利用規約」「著作権」「プライバシーポリシー」「ライセンス」などが書かれていそうなページを自動で探す補助ツールを作成しました。
これは、地域日本語教育の実践で使われる教材・地域素材・Webページなどについて、利用文脈や利用権リスクを保守的に整理するためのMVPであり、HTMLで書かれています。

---

## Transformative Practice Logの目的

Transformative Practice Log は、地域日本語教室で行われた実践を、単なる授業記録ではなく、次回以降の対話や振り返りにつながる「対話型ポートフォリオ」として蓄積するための仕組みです。

教案、授業記録、使用した地域素材、授業中に生まれた対話や気づきをもとに、実践の文脈を記録します。

特に重視するのは、教材そのものではなく、教材や地域素材が使われた「文脈」です。

たとえば、次のような観点を記録対象にします。

- なぜその素材を使ったのか
- どのような場面で使ったのか
- どのような対話が生まれたのか
- どのような配慮が必要だったのか
- どのような地域接続が生まれたのか
- どのような参加可能性が開かれたのか
- 利用権上のリスクはあるか
- 再利用時にどのような確認が必要か


## 背景

地域日本語教室では、パンフレット、チラシ、地図、回覧板、地域のお知らせ、写真、Webページなど、生活に根ざした地域素材が使われることがあります。

しかし、それらの素材については、次のような課題があります。

- 利用権が曖昧になりやすい
- AI入力やAI加工の扱いが不透明になりやすい
- 実践知が個人の経験に閉じやすい
- 地域素材が「どのように使われたか」が記録されにくい
- 授業中に生まれた対話や気づきが残りにくい
- 地域社会に対する教育的・社会的価値が可視化されにくい
- 学習者・支援者・地域素材・場の関係性の変化が記録されにくい

そこで本プロジェクトでは、地域日本語教育の実践を「利用実態ベース」で記録し、将来的な利用許諾交渉、実践知の共有、学習者や支援者の振り返りに活用できる形で蓄積することを目指します。

## このリポジトリで作成したMVPツール

### 法務系ページ自動検出ツール

URLを1つ入力すると、そのサイト内にある以下のようなページを探すHTMLツールです。

- 利用規約
- 著作権
- コピーライト
- ライセンス
- 無断転載に関する案内
- プライバシーポリシー
- 個人情報保護方針
- 特定商取引法に基づく表記
- サイトポリシー
- 免責事項

地域素材やWebページを授業で利用する前に、利用条件を確認するための補助ツールとして使うことを想定しています。

## このツールでできること

入力欄にURLを1つ入れると、次の処理を行います。

1. 入力されたURLのトップページHTMLを取得する
2. ページ内のすべてのリンクを取得する
3. リンクテキストを確認する
4. リンク先URLのパスを確認する
5. 「利用規約」「著作権」「プライバシー」などに関係しそうなリンクを抽出する
6. よくある法務系ページのパスも推測して確認する
7. 関連度が高そうな順にリンク一覧を表示する

## 使い方

### 1. HTMLファイルを開く

`index.html` をブラウザで開きます。
サーバーを用意しなくても、ローカルファイルとして開いて使えます。

### 2. URLを入力する

調べたいサイトのURLを1つ入力します。

例：

- 自治体サイト
- 地域団体のサイト
- 公共施設のサイト
- NPOのサイト
- 教材配布元のサイト
- 地域イベントの案内ページ

### 3. 「検出する」を押す

ページ取得と解析が始まります。
処理中はローディング表示が出ます。

### 4. 候補リンクを確認する

見つかった候補が、関連度の高そうな順に表示されます。
各リンクは別タブで開けます。

### 5. 必ず目視確認する

このツールは、あくまで候補ページを探す補助ツールです。
実際の利用条件、禁止事項、引用条件、転載条件、AI利用の可否などは、必ずリンク先ページを目視で確認してください。

## 自動取得できない場合

Webブラウザ上のJavaScriptで外部サイトを取得しようとすると、通常はCORSというセキュリティ制限によりブロックされることがあります。
このツールでは、ブラウザだけで動かせるように、公開プロキシAPIである AllOrigins を経由してHTMLを取得しています。

ただし、以下のような場合は取得できないことがあります。

- 対象サイトが自動アクセスをブロックしている
- セキュリティシステムがbotアクセスと判断している
- CAPTCHAが表示される
- Cloudflareなどの保護ページが表示される
- 公開プロキシ側が一時的に利用できない
- 対象サイトの応答が遅い

その場合は、ツール内に「HTMLソース貼り付け枠」が表示されます。
対象サイトをブラウザで開き、HTMLソースをコピーして貼り付けると、そのHTML内のリンクを解析できます。

## HTMLソース貼り付け解析について

HTMLソース貼り付け解析では、貼り付けたHTMLの中にあるリンクをブラウザ内で解析します。
この処理は、入力されたHTML文字列からリンク候補を抽出するためのものです。
自動取得ができないサイトでも、利用規約や著作権ページへのリンクを探せる可能性があります。

## 想定する利用場面

このツールは、地域日本語教育の実践において、以下のような場面で使うことを想定しています。

- 地域素材を授業で使う前の利用条件確認
- Webページを教材化する前の権利確認
- AIに入力してよい素材かどうかの事前確認
- Practice Log に出典や利用条件を記録する前の下調べ
- 利用許諾が必要かどうかを判断するための一次確認
- 地域素材の再利用リスクを整理するための補助

## Practice Log との関係

このツールは、Transformative Practice Log 全体の中では、地域素材やWebページの利用条件を確認するための補助ツールです。

Practice Log では、地域素材について次のような情報を記録することを想定しています。

- 出典
- URL
- 利用文脈
- 改変有無
- AI加工有無
- 配布有無
- 許諾状況
- 再利用時の注意点
- 利用権上のリスク
- 次回利用時に確認すべきこと

このツールは、そのうち「URL」「出典」「利用条件確認」「再利用時の注意点」を整理するための入口として使います。

## 注意事項

このツールは、法的判断を行うものではありません。
表示される結果は、リンクテキストやURLパスをもとにした機械的な候補です。
次の点に注意してください。

- 候補ページが見つかっても、利用が許可されているとは限りません。
- 候補ページが見つからなくても、自由に利用できるとは限りません。
- 利用規約や著作権表示は、必ず人間が確認してください。
- AI入力、AI加工、再配布、公開利用については、特に慎重に確認してください。
- 判断に迷う場合は、権利者や管理者に確認してください。
- このツールの結果だけを根拠に、教材の再配布や公開を判断しないでください。


## プライバシーと外部通信について

このツールは、入力されたURLのHTMLを取得するために、公開プロキシAPIである AllOrigins を利用します。
そのため、自動取得を行う場合、入力したURLは AllOrigins に送信されます。
一方、HTMLソース貼り付け解析では、貼り付けたHTMLをブラウザ内で解析します。
ただし、このツールはMVPであり、利用環境やブラウザの挙動を完全に保証するものではありません。
機密性の高い情報、非公開ページ、ログイン後のページ、個人情報を含むHTMLは貼り付けないでください。


## MVPで検証したいこと

このMVPでは、次のことを検証します。

- 地域素材の利用条件確認をどこまで簡略化できるか
- 法務系ページ候補を自動で見つけることが実践現場で役立つか
- Practice Log に記録するための出典確認を支援できるか
- 利用権リスクを「要確認」として保守的に整理しやすくなるか
- 非エンジニアでも使える形で実装できるか
- GitHub Pages で簡単に公開・共有できるか
