# 第5回課題



lecture3では、外国ルーツの人の生活支援をテーマにVPCを作成した。

今回は、地域日本語教室の実践から、VPCを再設計した。





## 新テーマ

地域日本語教育における「利用実態ベース交渉」を支えるObsidian + AI MVP設計





## 背景

地域日本語教室では、学校教育とは異なり、著作物の利用ルールが厳しく、また正式教材購入を前提にした運営が難しい。

そのため、地域素材（レアリア）を活用することもある。



しかし、現場では以下の問題がある。

- 利用権が曖昧

- AI入力や加工利用の扱いが不透明

- 実践知が属人化しやすい

- 「どのように使われたか」が記録されない

- 社会的価値が可視化されない



そこで、「地域コンテンツの利用権を、AI活用によって利用実態ベースで交渉可能にする」

というテーマにピボットした。

このMVPでは、教材そのものではなく、

- 利用文脈

- 対話履歴

- 配慮

- 社会的価値

をPractice Logとして記録する。
